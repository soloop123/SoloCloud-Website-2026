Server Properties

Edit server.properties without opening the file

You can change your server.properties settings without ever opening the file. There's a search box at the top, and each setting gets its own card with a short note on what it does: MOTD, max players, default game mode, difficulty, hardcore and so on. Press Save changes, or Save & restart if you want it applied right away. Network settings like port and RCON are hidden on purpose because we manage those for you.
